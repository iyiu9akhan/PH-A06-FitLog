Project Name : DevLog

Description : FitLog is a minimalist gym companion web app where user can browse various workouts, view details information for each equipments , difficulty, sets , reps, duration , calories , rating , instructions and add them to "Today's Plan" or "Save for later'. This web app fetches workout data from an external APi and manages the user's plan/save state on the client side using react context.


Technology used:

- Next.js
- React + React Toastify
- TypeScript
- ReactContext API
- TailwindCSS


Features:

- Workout Library
- Dynamic Workout Details Page
- Today's Plan Management
- Save for Later (Bookmark)
- My Plan Dashboard
- Sort Functionality
- Delete/Remove Workout
- Custom Toast Notification System
- Fully Responsive UI
